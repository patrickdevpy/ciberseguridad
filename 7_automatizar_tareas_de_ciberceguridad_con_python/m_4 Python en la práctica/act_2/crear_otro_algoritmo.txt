Se ha agregado una línea de código que contiene el método .Join () al código para que el archivo pueda actualizarse. Esto es necesario porque ip_addresses debe estar en formato de cadena cuando se usa dentro de la instrucción para reescribir el archivo.

El método .Join () toma un iterable (como una lista) y concatena cada elemento en una cadena. El método .Join () se aplica a una cadena que consiste en el carácter que se utilizará para separar cada elemento en el Iterable una vez que se convierte en una cadena. En el siguiente código, el método se aplica a la cadena "", que contiene solo un carácter espacial. El argumento del método .Join () es el iterable que desea convertir, y en este caso, eso es IP_Addresses. Como resultado, convierte ip_addresses de una lista nuevamente en una cadena con un espacio entre cada elemento y el siguiente.

Conclusión
¿Cuáles son sus conclusiones clave de este laboratorio?

Python tiene funciones y sintaxis que lo ayudan a importar y analizar archivos de texto.
La instrucción With le permite manejar los archivos de manera eficiente.
La función Open () le permite importar o abrir un archivo. Toma el nombre del archivo como el primer parámetro y una cadena que indica el propósito de abrir el archivo como el segundo parámetro.
Especifique "R" como el segundo parámetro si está abriendo el archivo para fines de lectura.
Especifique "W" como el segundo parámetro si está abriendo el archivo para fines de escritura.
El método .read () le permite leer en un archivo.
El método .Write () le permite agregar o escribir a un archivo.
Puede usar un bucle for para iterar en una lista.
Puede usar una instrucción IF para verificar si un valor dado está en una lista y ejecutar una acción específica si es así.
Puede usar el método .split () para convertir una cadena en una lista.
Puede usar Python para comparar el contenido de un archivo de texto con elementos de una lista.
Los algoritmos se pueden incorporar a las funciones. Al definir una función, debe especificar los parámetros que recibe y las acciones que debe ejecutar.
