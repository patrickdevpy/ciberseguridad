Conclusión
¿Cuáles son sus conclusiones clave de este laboratorio?

La depuración es una práctica esencial que los analistas usan para identificar errores en el código y solucionarlos para garantizar que el código se ejecute sin problemas.
Python ejecuta código de arriba a abajo y se detiene una vez que encuentra un error. Entonces, si hay múltiples errores en una celda de código, el mensaje de error salido generalmente mostrará el primer error.
En Python, los tipos comunes de errores incluyen errores de sintaxis, errores lógicos y excepciones.
Los errores de sintaxis a menudo implican puntuación como una falta: al final de un encabezado con declaración y un faltante, entre elementos en una lista.
Los errores lógicos pueden involucrar índices incorrectos al acceder a elementos desde una lista.
Las excepciones podrían implicar nombres de variables mal escritos o métodos de cadena llamados incorrectamente.
Una estrategia clave para la depuración es ejecutar código y examinar si produce los resultados previstos. Si la salida no es correcta, o si muestra un mensaje de error, use esto para identificar qué línea (s) del código podrían estar causando el problema. Después de arreglar el código, es importante ejecutarlo nuevamente para asegurarse de que todo funcione como se esperaba.
