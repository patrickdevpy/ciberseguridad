Ejemplar: desarrollar un algoritmo¶
Introducción
Un algoritmo es un conjunto de pasos que se pueden usar para resolver un problema. Los analistas de seguridad desarrollan algoritmos para proporcionar las soluciones que necesitan para su trabajo. Por ejemplo, un analista puede trabajar con usuarios que les traen dispositivos. El analista puede necesitar un algoritmo que primero verifique si un usuario está aprobado para acceder al sistema y luego verifica si el dispositivo que ha traído es el que se les asigna.

En este laboratorio, desarrollará un algoritmo en Python que automatiza este proceso.

Consejos para completar este laboratorio
Guión
En este laboratorio, está trabajando como analista de seguridad y es responsable de desarrollar un algoritmo que conecta a los usuarios con sus dispositivos asignados. Escribirá un código que indica si un usuario está aprobado en el sistema y ha llevado su dispositivo asignado al equipo de seguridad.

Tarea 1
Trabajará con una lista de nombres de usuario aprobados junto con una lista de los dispositivos aprobados asignados a estos usuarios. Los elementos de las dos listas están sincronizados. En otras palabras, el usuario en el índice 0 en aprobado_users usa el dispositivo en el índice 0 en aprobado_devices. Más tarde, esto le permitirá verificar si el nombre de usuario y la ID de dispositivo ingresado por un usuario corresponden entre sí.

Primero, para explorar cómo funcionan los índices en las listas, ejecute la siguiente celda de código tal como está y observa la salida. Luego, reemplace cada 0 con otro índice y ejecute la celda para observar lo que sucede.

# Asignar `aprobado_users` a una lista de nombres de usuario aprobados
​
aprobado_users = ["elarson", "bmoreno", "tshah", "sgilmore", "Eraab"]
​
# Asignar `aprobado_devices` a una lista de ID de dispositivo que corresponden a los nombres de usuario en 'aprobado_users`
​
aprobado_devices = ["8RP2K75", "HL0S5O1", "2YE3LZG", "4N482TS", "A307VIR"]
​
# Muestra el elemento en el índice especificado en `aprobado_users`
​
imprimir (aprobado_users [0])
​
# Muestra el elemento en el índice especificado en `aprobado_devices`
​
print (aprobado_devices [0])
​
elarson
8RP2K75
Pregunta 1
¿Qué observó sobre la salida cuando se muestra_users [0] y cuando se muestra_devices [0]? ¿Qué sucede cuando reemplaza cada 0 con otro índice?

Cuando se muestra_USERS [0], la salida es el primer nombre de usuario aprobado de aprobado_users. Cuando se muestra_devices [0], la salida es la primera ID de dispositivo de aprobado_devices. Cuando reemplaza cada 0 con otro índice, la salida es el elemento en ese índice en aprobado_users, seguido del elemento en ese índice en aprobado_devices. Por ejemplo, si reemplaza cada 0 con 2, la salida es el elemento en el índice 2 en aprobado_users, seguido del elemento en el índice 2 en aprobado_devices.

Después de que Python ingresa al condicional interno, ¿qué sucede cuando el dispositivo_id es correcto y qué sucede cuando el dispositivo_id es incorrecto?

Lo siguiente sucede después de que Python ingresa al condicional interno:

Cuando el dispositivo_id es incorrecto, la condición interna IF se evalúa en falso, Python ingresa al caso de lo contrario y se muestra un mensaje de que la ID del dispositivo no es el dispositivo diseñado por el usuario.
