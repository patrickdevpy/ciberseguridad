¡Bienvenido de nuevo! vamos a hablar del shell de Linux. 
Esta parte de la arquitectura de Linux es donde ocurrirá la acción para usted como analista de seguridad. 
Hemos introducido el shell con otros componentes del OS Linux anteriormente , pero echemos un vistazo más profundo a lo que es 
el shell y lo que hace. 
El shell es el intérprete de la línea de comandos. 
Esto significa que le ayuda a comunicarse con el sistema operativo a través de la línea de comandos. 
Previamente, hablamos de una interfaz de línea de comandos. Esencialmente, se trata del shell. 
El shell proporciona la interfaz de línea de comandos para que usted interactúe con el OS. Para decirle al OS lo que debe hacer, 
usted introduce comandos en esta interfaz. 
Un comando es una instrucción que le dice al ordenador que haga algo. 
El shell se comunica con el kernel para ejecutar estos comandos. 
Antes, hablamos de cómo el sistema operativo ayuda a los humanos y a los ordenadores a hablar entre sí. El shell es la parte del SO 
que le permite hacer esto. 
Piense en él como un intérprete de lenguaje muy útil entre usted y su sistema. 
Como usted no habla lenguaje informático o binario , no puede comunicarse directamente con su sistema. 
Aquí es donde el shell entra para ayudarle. 
Su SO no necesita el shell para la mayor parte de su trabajo, pero es una interfaz entre usted y lo que su sistema puede ofrecerle. 
Le permite realizar operaciones matemáticas, ejecutar pruebas y ejecutar aplicaciones. 
Más importante aún, le permite combinar estas operaciones y conectar aplicaciones entre sí para realizar tareas complejas y automatizadas. 
Al igual que hay muchas distribuciones de Linux, hay muchos tipos diferentes de shell. 
En este curso nos centraremos principalmente en el shell Bash. 
Continuemos aprendiendo más sobre el shell.
